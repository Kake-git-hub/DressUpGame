# 🎀 きせかえゲーム (Dress-Up Game)

子供向け2D着せ替えWebゲーム（iPad 横向き用）

## 📌 現在のバージョン: v0.11.0

- 遊ぶ: https://kake-git-hub.github.io/DressUpGame/
- 素材（ドール・服・背景）: [DressUpGame-content](https://github.com/Kake-git-hub/DressUpGame-content) から配信

---

## 🎮 遊び方

1. アプリを開く（服や背景は自動で読み込まれます。取り込み操作は不要です）
2. **カテゴリ** をタップしてアイテム一覧を表示
3. **アイテム** をドラッグしてドールにドロップ
4. **👗ボタン** で服を調整。服のまわりの枠をドラッグで移動、右下のつまみで大きさと向き、左上の × で脱がせる（調整は続き、残りの服に切り替わる）。右のボタンで重なりの前後と色、左の一覧で調整する服を切り替え（服を着ていないときはドールを調整）
5. **🖼️はいけい** で背景を変更
6. **📷ボタン** で写真を保存
7. **🔄ボタン** で服と背景をリセット

一度開けば、オフラインでも遊べます。アプリは開いたとき・戻ってきたときに新しい版を確認し、あれば自動で更新します。

## 🧵 素材について

素材は別リポジトリ [DressUpGame-content](https://github.com/Kake-git-hub/DressUpGame-content) にあり、`manifest.json`（一覧）と `files/`（画像）で構成されます。服とドールは、透明でない部分で切り抜いて保存し、元の位置は一覧ファイルに持たせています。

### 素材スタジオ（PC 用の制作画面）

AI が作った画像（ドールが単色のシルエット、背景も単色）を入れると、切り抜き・ドールへの位置合わせ・サムネイル作成を自動で行い、カテゴリと名前を決めて保存・公開できます。

1. `DressUpGame` と `DressUpGame-content` を同じ階層に置く（別の場所なら、環境変数 `CONTENT_DIR` で指定）。
2. `npm run studio` を実行すると、ブラウザでスタジオ（`/DressUpGame/studio.html`）が開く。
3. 「ドールの範囲」でドール（背景が透明な画像）を追加すると、体の部位とカテゴリごとの範囲が自動でできる（ずれていれば直す）。
4. 「テーマから作る」で、テーマ（自由に書く）・絵柄（アニメ、リアル、ゆめかわパステル、絵本・水彩、ポップから選ぶ）・作るもの（カテゴリか背景）・枚数（ふつうは 1）を決めて「作る」。できた候補を確かめて保存する。
5. 手持ちの画像は「画像から追加」で選ぶ → プレビューを見て、必要なら位置の微調整・消しゴム・復元 → カテゴリと名前を決めて保存。ほかの AI で作るときの基準画像（シルエット）もここでダウンロードできる。
6. 「ゲームで確認」で、保存した素材をゲームで試す。「公開」で素材リポジトリに commit・push する（数分で iPad に届く）。

手袋・くつ・くつしたなどは、保存の前に「手足の先を服に合わせる」を選べる（カテゴリ名から自動で入る）。着ているあいだ、服からはみ出したドールの指先・足先を隠すので、AI が手足の形を少し変えて描いても、服と手足が食い違わない。

AI が作った画像は、全体をドールに合わせたあと、手・腕・足などの部位ごとにも位置を合わせ直す（AI がシルエットを描き直したときの、指先などの小さなずれを直すため）。AI への指示には、キャラクター名・作品名・ブランド名を書かないよう毎回指示している。それでも画像 AI に内容の決まりで断られたときは、説明文を書き直して 1 回だけやり直す。

テーマからの自動生成を使うには、`.env.example` を `.env.local` という名前でコピーし、API キーを貼り付けます（PC の環境変数でも可）。`.env.local` は git に入りません。キーは画面には入力しません。

| 環境変数 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API のキー（品目の企画と検品） |
| `GEMINI_API_KEY` | Gemini API のキー（画像生成） |
| `STUDIO_DAILY_IMAGE_LIMIT` / `STUDIO_RUN_IMAGE_LIMIT` | 画像生成の上限（1 日 / 1 回の実行）。既定は 60 枚 / 30 枚 |
| `STUDIO_GEMINI_IMAGE_SIZE` | 画像の大きさ（`1K` / `2K` / `4K`）。大きいほど高い。既定は `1K` |
| `STUDIO_MAX_ATTEMPTS` | 1 品目あたりの生成回数（作り直しを含む、1〜3）。既定は 1（自動の作り直しなし。断られたときの書き直しだけは 1 回やり直す） |
| `STUDIO_CLAUDE_MODEL` / `STUDIO_GEMINI_MODEL` | 使うモデル。既定は `claude-opus-5-5` / `gemini-nano-banana-2.1` |

スタジオはゲームとは別のページで、遊ぶ側の読み込みには含まれません。公開サイト上では API が無いため動きません（サーバーへの設置は今後の段階）。計画と結果は `docs/superpowers/plans/2026-11-16-studio.md` を参照してください。
