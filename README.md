# 🎀 きせかえゲーム (Dress-Up Game)

子供向け2D着せ替えWebゲーム（iPad・スマホ。横でも縦でも遊べます）

## 📌 現在のバージョン: v0.39.1

- 遊ぶ: https://kake-git-hub.github.io/DressUpGame/
- 素材（ドール・服・背景）: [DressUpGame-content](https://github.com/Kake-git-hub/DressUpGame-content) から配信

---

## 🎮 遊び方

1. アプリを開くと、ホーム画面が出ます。**あそぶ** を押す（服や背景は自動で読み込まれます。取り込み操作は不要です）
2. **カテゴリ** をタップしてアイテム一覧を表示
3. **アイテム** をドラッグしてドールにドロップ
4. **👗ボタン** で服を調整。服のまわりの枠をドラッグで移動、右下のつまみで大きさと向き、左上の × で脱がせる（調整は続き、残りの服に切り替わる）。右のボタンで色、左の一覧で調整する服を切り替え（服を着ていないときはドールを調整）。左の一覧は重なりの順番（上が手前、まんなかにドール）で、服の絵をつかんで上下に動かすと、その位置に入れ替わる（ドールより下へ動かすと、ドールの後ろに回る。▲▼ でも 1 つずつ動かせる）。髪は、前髪とうしろがみの 2 枚が一緒に動き、色も一緒に変わる（重なりの前後だけは 1 枚ずつ）。黒い髪や服は、色スライダーで黒い所に色が付く
5. **セット**（あるドールだけ。メニューの先頭）をドラッグすると、同じテーマの服が全部、一度に着く（パーツは、ふつうの服として各カテゴリにも入っていて、1 点ずつ着替えられる）
5. **🖼️はいけい** で背景を変更
6. **📷ボタン** で写真を保存
7. **🔄ボタン** で服と背景をリセット
8. **🏠ボタン** でホームにもどる

ホームの **つくる**（AI で服を作る）と **クローゼット**（作った服の一覧。名前・色・並びを直す、消す）は、作者が教えた端末にだけ出ます（販売を始めるまで）。

縦に持つと、メニュー類は画面の下に並びます（上からカテゴリの行・服の行・ボタンの行。服は上へドラッグして着せ、行は横になぞって流す）。持ち替えても、服の位置はドールに対して同じです。版数は、画面の右上に小さく出ます。一度開けば、オフラインでも遊べます。アプリは開いたとき・戻ってきたときに新しい版を確認し、あれば自動で更新します。

## 🧵 素材について

素材は別リポジトリ [DressUpGame-content](https://github.com/Kake-git-hub/DressUpGame-content) にあり、`manifest.json`（一覧）と `files/`（画像）で構成されます。服とドールは、透明でない部分で切り抜いて保存し、元の位置は一覧ファイルに持たせています。

### 素材スタジオ（PC 用の制作画面）

AI が作った画像（ドールが単色のシルエット、背景も単色）を入れると、切り抜き・ドールへの位置合わせ・サムネイル作成を自動で行い、カテゴリと名前を決めて保存・公開できます。

1. `DressUpGame` と `DressUpGame-content` を同じ階層に置く（別の場所なら、環境変数 `CONTENT_DIR` で指定）。
2. `npm run studio` を実行すると、ブラウザでスタジオ（`/DressUpGame/studio.html`）が開く。起動したときと画面を開いたときに、公開されている素材（ほかの PC やクラウドから公開した新しいドールなど）を自動で取り込む。PC に未公開の変更（服を消した・足した・名前を変えた、など）が残っていても、それを残したまま取り込む（一覧ファイルは、手元の変更を、公開されている新しい内容に重ねる。取り込む前の一覧は、素材フォルダの `.git/studio-backup/` に控えを残す）。「公開」を押したときも、先に取り込んでから公開する。画面の上には、スタジオの版数と、取り込みの結果（「素材の取り込み: …」）がいつも出る。**新しいドールが出てこないとき**は、(1) 版数が README の版数と同じか（古ければ、`DressUpGame` のフォルダで `git checkout main` と `git pull` をしてから、スタジオを起動し直す）、(2) 取り込みの結果に何と出ているか、を見る。
3. 「ドールの範囲」でドール（背景が透明な画像）を追加すると、体の部位とカテゴリごとの範囲が自動でできる（ずれていれば直す）。
4. 「テーマから作る」で、テーマ（自由に書く）・絵柄（アニメ、マンガ、リアル、ゆめかわパステル、絵本・水彩、ポップから選ぶ）・作るもの（カテゴリ・背景・セット）・枚数（ふつうは 1）を決めて「作る」。できた候補を確かめて保存する。「セット」を選ぶと、入れるカテゴリにチェックを付ける欄が出て、選んだカテゴリごとに 1 点ずつ、色と飾りをそろえて作る（画像は 1 点ずつ作るので、4 つ選べば 4〜8 枚）。候補は「ぜんぶ保存」でまとめて保存できる（警告のあるカード・同じ名前の服があるカードは、確かめ待ちとして残る）。保存した服は、ふつうの服として各カテゴリに入り、「一覧」でセットの名前を変える・服をセットから外す・服を消す、ができる（最後の 1 点が無くなると、セットも消える）。
5. 手持ちの画像は「画像から追加」で選ぶ → プレビューを見て、必要なら位置の微調整・消しゴム・復元 → カテゴリと名前を決めて保存。ほかの AI で作るときの基準画像（シルエット）もここでダウンロードできる。
6. 「一覧」の「ならべかえ」で、カテゴリ・セット・服をつかんで動かすと、ゲームのメニューの順番が変わる（「くわしく」で、名前・カテゴリ・セット・位置と大きさ・消す）。
7. 「ゲームで確認」で、保存した素材をゲームで試す。「公開」で素材リポジトリに commit・push する（数分で iPad に届く）。

品目の種類ごとに、作り方が違う。

| 品目 | AI に渡す図 | 取り出し方 |
|---|---|---|
| トップス・ボトムス・ドレス・ソックスなど | 全身の単色シルエット | 色で抜く |
| ヘアスタイル | ドールの**本物の上半身（頭〜腰）を拡大した図**（顔なし） | 元の図と違う所が髪。前髪と後ろ髪の 2 枚に分ける（ゲームでは 1 点として着せる）。髪が肌に落とした影は、髪に入れない |
| ぼうし | **上半身（頭〜腰）を拡大した**単色シルエット | 色で抜く |
| くつ | ドールの**本物のすねから下を拡大した図** | 足首から下は絵ごと**差し替える**（着ているあいだ、ドールの足は隠す）。足首より上は、元の図と違う所だけ（ブーツの筒など） |
| てぶくろ | ドールの**本物の左右の腕を拡大して並べた図** | 手首から先を絵ごと差し替える。上は、元の図と違う所だけ |
| かお | ドールの本物の頭を拡大した図 | 頭ごと「お面」として重ねる |

拡大図に描かせるので、同じ大きさ（1K）の画像でも、頭や足もとの画素が 2〜3 倍になる。差し替え式は、ドールの足と靴の形が違ってもはみ出さないので、甲の開いた靴やサンダルも作れる。髪は腰までの長さで作る（拡大図に収めるため）。素材フォルダの `studio/masters/` に、ドールの画像と同じ名前の 2 倍の画像があれば、拡大図はそこから作る（ぼやけない）。

くつしたなど、全身シルエットで作った手足の品目は、保存の前に「手足の先を服に合わせる」を選べる（着ているあいだ、服からはみ出したドールの指先・足先を隠す）。

#### 新しいドールを作る

服・靴・手袋・髪を描かせやすい姿勢（約 5.5 頭身、腕は体から離す、手は手のひらが見える「パー」、脚の間にすき間、足は地面にべったりでつま先は外向き、細い輪郭線、髪と顔なし）を、指示文にまとめてある（`tools/studio/dollPrompt.ts`）。

```bash
# 絵柄の見本にするドールの画像から、候補を作る（緑の背景、2K）。
# 最後に boy を付けると、見本のドールと同じ姿勢・大きさのまま、男の子（下着は白い短パンだけ。上半身は何も着ない）にする
npx tsx tools/studio/makeDoll.ts generate <見本の画像> <出力フォルダ> [枚数] [girl|boy]
# 選んだ候補を、背景を抜いて素材フォルダに登録する（2 倍の元画像も studio/masters/ に残す）
npx tsx tools/studio/makeDoll.ts import <候補の画像> <素材フォルダ> <名前> [カテゴリを写すドールの ID]
# いまあるドールの絵だけを差し替える（下着を変えたときなど）。いまのドールと同じ位置合わせで置くので、服はそのまま使える。
# 新しい絵は、いまのドールのもとの絵を見本にして、同じ姿勢・大きさで作ること
npx tsx tools/studio/makeDoll.ts replace <新しい絵> <素材フォルダ> <ドールの ID> <いまのドールのもとの絵>
```

服が 1 点も無いドール（作りかけ）は、スタジオには出るが、ゲームには出ない。最初の 1 点を保存して公開すると、ゲームでも選べるようになる。

Claude API のキーが無い環境では、品目を JSON で渡して画像生成だけを回せる（`npx tsx tools/studio/tryItems.ts`。見た目の検品は人が行う。`--with <品目の ID>` で靴下などを重ねた絵も書く。AI に渡した絵と返ってきた絵も残すので、処理を直したときに、作り直さずに確かめられる）。

AI が作った画像は、全体をドールに合わせたあと、手・腕・足などの部位ごとにも位置を合わせ直す（AI がシルエットを描き直したときの、指先などの小さなずれを直すため）。AI への指示には、キャラクター名・作品名・ブランド名を書かないよう毎回指示している。それでも画像 AI に内容の決まりで断られたときは、説明文を書き直して 1 回だけやり直す。

テーマからの自動生成を使うには、`.env.example` を `.env.local` という名前でコピーし、Gemini の API キーを貼り付けます（PC の環境変数でも可）。Claude のキーは、無くても動きます（v0.25.0 から。あれば、企画と検品に Claude を使い、無ければ Gemini の文章のモデルを使います）。`.env.local` は git に入りません。キーは画面には入力しません。

| 環境変数 | 内容 |
|---|---|
| `GEMINI_API_KEY` | Gemini API のキー（画像生成。Claude のキーが無ければ、品目の企画と検品も） |
| `ANTHROPIC_API_KEY` | Claude API のキー（無くてもよい。あれば、品目の企画と検品に使う） |
| `STUDIO_DAILY_IMAGE_LIMIT` / `STUDIO_RUN_IMAGE_LIMIT` | 画像生成の上限（1 日 / 1 回の実行）。既定は 上限なし / 30 枚 |
| `STUDIO_GEMINI_IMAGE_SIZE` | 画像の大きさ（`1K` / `2K` / `4K`）。大きいほど高い。既定は `1K` |
| `STUDIO_MAX_ATTEMPTS` | 1 品目あたりの生成回数（作り直しを含む、1〜3）。既定は 2（できた絵を検品し、不合格なら直し方の指示を添えて 1 回だけ自動で作り直す）。1 にすると作り直さない（断られたときの書き直しだけは 1 回やり直す） |
| `STUDIO_CLAUDE_MODEL` / `STUDIO_GEMINI_MODEL` / `STUDIO_GEMINI_TEXT_MODEL` | 使うモデル。既定は `claude-opus-5-5` / `gemini-nano-banana-2.1`（画像）/ `gemini-3.8-flash`（文章） |

スタジオはゲームとは別のページで、遊ぶ側の読み込みには含まれません。公開サイト上では API が無いため動きません（サーバーへの設置は今後の段階）。計画と結果は `docs/superpowers/plans/2026-11-16-studio.md` を参照してください。
