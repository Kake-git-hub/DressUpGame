# iPad とスマホ、v0.37.0: Google のログイン（ためしの版）ができた

- 報告: GitHub の Issue 8（2026-11-24、作者）。「ログインできた」。そのあと、カードで聞いたこと（同じ日）。
- 端末: iPad のホーム画面のアプリ（`standalone: true`、1024×748、画素の細かさ 2。Safari 17 系の名乗り）。スマホは、Android のホーム画面のアプリ。
- 作者の設定（`docs/firebase-setup.md` の 2-10）は、済んでいる（2026-11-24 に、こちらから確かめた: Google のログインが有効。ウェブ用の `client_id` が返る）。

## 分かったこと（作者の答え）

| 端末 | 方法 1（小さい窓） | 方法 2（画面を移る） |
|---|---|---|
| iPad（ホーム画面のアプリ） | **できた** | **できた** |
| スマホ（Android、ホーム画面のアプリ） | 「この Google のアカウントは、ほかの端末で使われています…次の版で…」と出た（2 台めで、チケットか服がある端末として、正しい動き。Google の画面が開いて、戻って来られた、ということ。どちらの方法で押したかは、聞いていない） | |

- 心配していた 2 点は、どちらも通った: iPad のホーム画面のアプリで、小さい窓の結果がアプリに戻ること。方法 2 の証明（`nonce` 入り）を、Firebase が受け取ること。
- 方法 2 の `client_id` を、アプリが Firebase に聞いて調べる道（`accounts:createAuthUri`）も、動いた（方法 2 ができたので）。

## きろくから読めたこと・読めなかったこと

- きろくに残っていたのは、`login out`（ログアウト）の 1 行だけ。ログインの行（`login start …`・`login result …`）は、残っていなかった。
- 理由: きろくは「今回」と「前の回」の 2 回ぶんしか持たない。ログイン・ログアウトは、読み込み直しをはさむので、試しているうちに、前の行が押し出される。**どの方法でできたかは、きろくからは分からなかった**（作者に聞いた）。
- 直すこと（次の版）: ログインの行は、読み込み直しをはさんでも残す。
