# テーマの細かさで生成の幅を変える（v0.47.0） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** アプリの「つくる」で、細かいテーマはそのとおりに、大きいテーマは毎回ちがう服になるように、品目の説明を作る段に「測る → くじ → 最近と違うものに」を足す。

**Architecture:** 新しい `tools/studio/themeWidth.ts` が、軸とくじの表・細かさの数え方・くじ・頼みに足す行・テーマを測る AI の呼び出しを持つ。`planItems`・`planSet` は、足す行（`extra`）を受け取るだけ。`tools/cloud/studioCore.ts` の `startJob` が、企画の前に `themeWidth` を呼び、最近の服を集め、結果を仕事の記録に残す。アプリの画面は変えない。

**Tech Stack:** TypeScript、Vitest、Firebase Functions（`functions/` が `tools/` を取り込む）、Gemini の文章の AI（`TextAi`）。

**Spec:** `docs/superpowers/specs/2026-11-27-v0.47.0-generation-width-design.md`（試しの記録と下書き: `docs/superpowers/specs/2026-11-27-generation-width/`）

## Global Constraints

- 画像生成は、作者の了承なしに 1 枚も使わない（Task 1〜5 は 0 枚）。
- `extra` を渡さない `planItems`・`planSet` の頼みの文は、いまと 1 文字も変えない（PC のスタジオは変えない）。
- 測る段は「つくる」を失敗させない: 失敗・時間切れ（8000 ms）・形のこわれた返事は、くじ 0 個・最近の服なしで、いままでどおりに企画する。
- 測る AI を呼ぶのは、チケットが足りると分かったあと。チケットを引くのは、いままでどおり企画のあと。
- 写真から顔を作るとき（`input.photo`）は、測らない・くじなし。
- 細かさ: 点 = 言っている軸の数 +（話題の言葉が 2 つ以上なら 1）。2 点以上 = `tight`（くじ 0）、1 点 = `normal`（1〜2 個）、0 点 = `wide`（2〜3 個）。
- 最近の服: 新しい順に 5 件まで。`failed` は入れない。`tight` のときは添えない。
- くじの表に入れない: はだ色に近いくつの色、季節を選ぶ素材（velvet・corduroy・knit・fleece）、ひざまでの髪。
- ドールの名前が `/おとこ|男|boy/i` に合うとき、`frilly: true` の候補を外す。
- コメント・テスト名は日本語（このリポジトリの書き方）。コミットの最後に、決められた 2 行を付ける。
- 版: アプリ `0.47.0`、`SERVER_API = 8`。`MIN_API` は上げない。

## Review Focus

1. 測る AI が、形は正しいが中身が全部 true の返事を返す（何でも「決まっている」）→ `tight`。くじ 0・最近の服なしで、いままでどおりの服ができること（Task 2 のテスト「全部 true」）。
2. 候補が 1 つも無い軸しか残っていない（テーマが、表のある軸を全部言った／おとこのこで frilly を外したら空）→ くじは引けた分だけ（0 個でもよい）で、落ちないこと（Task 1 のテスト「引ける軸が足りない」）。
3. 知らない名前のカテゴリ（作者がスタジオで作った「つばさ」など）→ 種類 `other` の軸で、落ちずにくじが引けること（Task 1）。
4. その人の仕事が 100 件ある／古い版の仕事（`v` なし、`description` が空）が混じる → 最近の服は 5 件で止まり、空の説明は入れないこと（Task 4）。
5. 60 文字いっぱいのテーマ・絵文字や改行の入ったテーマ → 測る頼みにそのまま入り、落ちないこと（Task 2 のテスト「長いテーマ」）。

### Task 1: 軸・細かさ・くじ・足す行（AI を呼ばない部分）

**Files:**
- Create: `tools/studio/themeWidth.ts`
- Test: `tools/studio/themeWidth.test.ts`

**Interfaces:**
- Produces:
  - `type WidthKind = 'dress' | 'tops' | 'bottoms' | 'shoes' | 'hat' | 'hair' | 'face' | 'other' | 'set'`
  - `type WidthLevel = 'tight' | 'normal' | 'wide'`
  - `interface WidthOption { en: string; ja: string; frilly?: true }`
  - `interface WidthAxis { id: string; ja: string; ask: string; options: WidthOption[] }`（`ask` = 測る頼みに書く、その軸の英語の説明。`options` が空の軸は、測るだけで、くじは引かない）
  - `interface WidthHint { axis: string; en: string; ja: string }`
  - `widthKind(categoryLabel: string): WidthKind` — `generate.ts` の `categoryKind` が `face`／`hair`・`backhair`／`shoes` を返せばそれ。ほかは名前で: `/ドレス|ワンピ|dress/i` → dress、`/トップス|シャツ|ブラウス|上着|tops?/i` → tops、`/ボトムス|スカート|パンツ|ズボン|bottoms?/i` → bottoms、`/ぼうし|帽子|hat|cap/i` → hat、ほか → other。
  - `axesFor(kind: WidthKind, dollName: string): WidthAxis[]` — 設計書 4-2 の表。おとこのこ（`/おとこ|男|boy/i`）なら `frilly` の候補を外した写しを返す。
  - `levelOf(fixed: string[], topics: string[]): WidthLevel`
  - `drawHints(level: WidthLevel, fixed: string[], axes: WidthAxis[], random: () => number): WidthHint[]`
  - `widthLines(level: WidthLevel, hints: WidthHint[], recent: string[]): string[]` — `planItems`・`planSet` の `extra` に渡す英語の行。文は、`docs/superpowers/specs/2026-11-27-generation-width/spike.mts` の `hintLines`・`avoidLines` を元に、ヒントの決まりに「drop a hint that does not suit the season or mood of the theme」を足す。`tight` のときは、きっちりの 1 文だけ（`recent` は使わない）。

### Task 4: `startJob` に、測る → くじ → 最近の服 を入れる

**Files:**
- Modify: `tools/cloud/studioCore.ts`（`CoreDeps`・`startJob`）、`tools/cloud/store.ts`（`JobDoc`）
- Test: `tools/cloud/studioCore.test.ts`

**Interfaces:**
- Consumes: Task 1〜3。
- Produces:
  - `CoreDeps.random?: () => number`（無ければ `Math.random`）、`CoreDeps.measureTimeoutMs?: number`（無ければ `MEASURE_TIMEOUT_MS`）
  - `JobDoc.width?: { level: WidthLevel | 'none'; hints: string[] }`（`hints` は日本語の名前。測らなかった写真の仕事には付けない。測れなかったら `{ level: 'none', hints: [] }`）
  - `recentDescriptions(jobs: JobDoc[], dollId: string, target: Target): string[]`（`studioCore.ts` から export。新しい順の `jobs` から 5 件まで）

決まり（`startJob` の中。チケットの確かめのあと、企画の前）:
- `photo` があれば、何もしない（`extra` なし、`width` なし）。
- 種類: セットなら `'set'`、1 点なら `widthKind(そのカテゴリのラベル)`。`axesFor(種類, doll.name)`。
- `measureTheme(text, { theme, categoryLabels: 頼んだカテゴリのラベル, axes }, deps.measureTimeoutMs)`。`null` なら `width = { level: 'none', hints: [] }`、`extra` なし。
