# v0.46.0: だれが開いても、ホーム画面への追加（インストール）・ブックマークをすすめる

## 1. 作者が決めたこと／こちらで決めたこと

- 作者の言葉（2026-11-27）:
  1. 「おしえる で共有した際にブックマークや PWA（インストール）を促すようにして」
  2. （おしえる の URL から開いた人にだけ出す形を作ったあとで）**「教えるに限らず、誰がアプリ開いてもインストールに誘導して」** → **出す相手は、だれでも。これは作者が決めた。**
- こちらで決めたこと（作者には、写真で見てもらう）:
  - 出し方は、**ホームを開いたときに出る小さな窓**（おしえる の窓と同じ見た目）。「あとで」か、窓の外を押すと閉じる。
  - **「あとで」のあと、20 時間は出さない**（あそんでホームにもどっても、読み込み直しても。だいたい「次の日に開くと、また出る」）。自動の更新・Google のログインの戻り・支払いの戻りは、画面を読み込み直すので、時刻で覚えないと、閉じたばかりの窓がまた出てしまう。
  - **「あとで」を合わせて 3 回押すか、追加できたら、もう出さない。** もうホーム画面から開いている（アプリとして開いている）人には、出さない。
  - 端末ごとに中身を変える（3 章）。
  - おしえる の画面に、1 行足した:「ひらいた ともだちにも、『ホームがめんに ついか』の あんないが でるよ」。
  - おしえる の URL は、いままでどおり（印は付けない）。

## 2. ほかの案（とらなかった理由）

- おしえる の URL に印（`?from=share`）を付けて、そこから開いた人にだけ出す: はじめは、こう作った。作者が「だれが開いても」と決めたので、やめた（印も外した）。
- ホームの下に、画面をふさがない小さなカードで出す: はじめは、こう作った。別の目のレビューで、小さい画面（iPhone SE の Safari・小さい Android・スマホの横）では、カードが「つかいかた」や「あそぶ」に重なると分かったので、窓に変えた（窓は、どの大きさでも収まる。1 回「あとで」を押す手間はある）。
- 閉じても、毎回ずっと出す: 入れたくない人・入れられない人（学校の端末など）が、毎回 1 回押すことになる。3 回でやめる。

## 3. 作り

- `src/home/installHint.ts`（画面の無い部分）:
  - `wantsInstallHint`: アプリとして開いていなくて、`done` でなく、`closed` が 3 未満で、最後の「あとで」（`at`）から 20 時間たっている。覚えは `localStorage` の `dressup_install_hint` = `{closed, at, done}`。**端末に覚えられないとき（保存が使えない）は、出さない**（閉じたことを覚えられず、毎回出てしまうので）。覚えがこわれていたら、はじめから数え直す。
  - `installKind`: 端末ごとの種類。`prompt`（ブラウザが追加の画面を出せる = 「ついかする」ボタン）／`ios`（共有ボタン →「ホーム画面に追加」）／`android`（メニュー →「ホーム画面に追加」）／`inapp`（LINE などの中の画面。「ブラウザで開く」）／`bookmark`（パソコン）。
  - `createInstallPromptStore`: ブラウザの知らせ（`beforeinstallprompt`・`appinstalled`）を覚える。案内を出す端末でだけ、ブラウザ自身の案内を止める。追加された知らせは、ホームを開いていないときに来ても、端末に覚える。
- `src/home/installBoot.ts`: 起動のいちばん最初（`main.tsx`）から、ブラウザの知らせを聞いておく（知らせは、開いてすぐに 1 回しか来ない）。
- `src/home/InstallHint.tsx`: 窓。`HomeScreen` の中に置く。
- E2E の決まり: `playwright.config.ts` の `storageState` で「もう出さない」にしてある（`dressup_install_hint` = `{"closed":0,"done":true}`）。案内のテスト（`e2e/home.spec.ts` の最後のまとまり）だけ、空の状態で開く。`e2e/guide.spec.ts` も、自分の `storageState` に同じ値を入れてある。**空の状態で開く新しいテストを書くときは、この値を入れないと、ホームに窓が出て、ボタンが押せない。**

## 5. 確かめられていないこと

- **実機では、1 回も試していない。** 写真は、Chromium に iPhone・Android・LINE の名のりをさせたもの。
- Android の Chrome で、本当に「ついかする」ボタンに変わるか（ブラウザの知らせは、条件がそろったときにだけ来る。来なければ、手順の形のまま）。
- iPhone・iPad の共有ボタンの場所は、ブラウザによって違う（Safari は下か上、Chrome は右上）。案内は、印の絵だけを見せている。
- Android の手順の「メニュー」の場所は、ブラウザによって違う（Chrome は右上、Firefox・Samsung は下）。
- LINE の中の画面の「ブラウザで開く」の場所と言い方は、LINE の版によって違う。
- いま、ブラウザで遊んでいる人（ホーム画面に追加していない人）にも、次に開いたときから、この窓が出る。
- サーバーは変えていない。画像生成 0 枚。
