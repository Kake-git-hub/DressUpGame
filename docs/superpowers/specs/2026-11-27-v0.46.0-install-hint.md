# v0.46.0: 「おしえる」で教えてもらって開いた人に、ホーム画面への追加・ブックマークをすすめる

作者の頼み（2026-11-27）:「おしえる で共有した際にブックマークや PWA（インストール）を促すようにして」。

## 1. 作者が決めたこと／こちらで決めたこと

- 作者の言葉は、上の 1 文だけ。**だれに・いつ出すかは、こちらで決めた**（カードで聞こうとしたが、カードが閉じてしまったので、いちばん素直な形で作り、公開の前に写真で見てもらう）。
- こちらで決めたこと:
  - 出すのは、**おしえる の URL・QR コードから開いた端末だけ**（ふつうに開いた人・もうホーム画面から開いている人には出さない）。
  - 出し方は、**開いたときに 1 回出る小さな窓**（おしえる の窓と同じ見た目）。「あとで」か、窓の外を押すと閉じる。その回は、あそんでホームにもどっても出ない。次に開くと、また出る。
  - 「あとで」を合わせて 3 回押すか、追加できたら、もう出さない。
  - おしえる の画面に、1 行足した:「ひらいた ともだちには、『ホームがめんに ついか』の あんないが でるよ」。

## 2. ほかの案（とらなかった理由）

- はじめて開いた人 全員に出す: おしえる と関係なく出る。いまブラウザで遊んでいる人にも出る。作者の言葉（「おしえる で共有した際に」）から遠い。あとで広げるのは簡単（`wantsInstallHint` の条件を変えるだけ）。
- おしえる の画面に文を足すだけ: 開いた人の画面は変わらないので、教えた子が口で伝えないと届かない。
- ホームの下に、画面をふさがない小さなカードで出す: はじめは、こう作った。別の目のレビューで、小さい画面（iPhone SE の Safari・小さい Android・スマホの横）では、カードが「つかいかた」や「あそぶ」に重なると分かったので、窓に変えた（窓は、どの大きさでも収まる。1 回「あとで」を押す手間はある）。

## 3. 作り

- `src/home/share.ts` の `shareUrl`: URL に `?from=share` を付ける。
- `src/home/installHint.ts`（画面の無い部分）:
  - `captureShareArrival`: 印があれば、端末に覚えて（`localStorage` の `dressup_install_hint` = `{closed, done}`）、URL から印を消す（ブックマークやホーム画面に印が残らないように。ほかの印と # は残す）。**LINE などの、アプリの中の画面では、印を消さない**（「ブラウザで開く」で開き直した先は、保存場所が別なので、印が無いと案内が出ない）。
  - `wantsInstallHint`: 覚えがあって、アプリとして開いていなくて、`done` でなく、`closed` が 3 未満。**端末に覚えられないときは、出さない。**
  - `installKind`: 端末ごとの種類。`prompt`（ブラウザが追加の画面を出せる = 「ついかする」ボタン）／`ios`（共有ボタン →「ホーム画面に追加」）／`android`（「︙」→「ホーム画面に追加」）／`inapp`（LINE などの中の画面。「ブラウザで開く」）／`bookmark`（パソコン）。
  - `createInstallPromptStore`: ブラウザの知らせ（`beforeinstallprompt`・`appinstalled`）を覚える。案内を出す端末でだけ、ブラウザ自身の案内を止める（ほかの端末では、いままでどおりブラウザに任せる）。追加された知らせは、ホームを開いていないときに来ても、端末に覚える。「あとで」で閉じたことは、その回のあいだ、ここが覚える（`snooze`）。
- `src/home/installBoot.ts`: 起動のいちばん最初（`main.tsx`）に、印の受け取りと、知らせの聞き始め。きろくに `share arrived`。
- `src/home/InstallHint.tsx`: 窓。`HomeScreen` の中に置く。

## 5. 確かめられていないこと

- **実機では、1 回も試していない。** 写真は、Chromium に iPhone・Android・LINE の名のりをさせたもの。
- Android の Chrome で、本当に「ついかする」ボタンに変わるか（ブラウザの知らせは、条件がそろったときにだけ来る。来なければ、手順の形のまま）。
- iPhone・iPad の共有ボタンの場所は、ブラウザによって違う（Safari は下か上、Chrome は右上）。案内は、印の絵だけを見せている。
- LINE の中の画面の「ブラウザで開く」の場所と言い方は、LINE の版によって違う。また、「ブラウザで開く」が、印の付いた URL をそのまま渡すかどうかは、試していない（渡さなければ、開き直した先では案内が出ない）。
- Android の手順の「メニュー」の場所は、ブラウザによって違う（Chrome は右上、Firefox・Samsung は下）。
- サーバーは変えていない。画像生成 0 枚。
